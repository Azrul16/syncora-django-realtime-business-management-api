Repository polish checklist:

- Keep the README current with setup, API docs, architecture, testing, and deployment notes.
- Keep `.env.example` complete, but never commit `.env`.
- Keep generated local artifacts out of commits unless intentionally publishing them.
- Preserve migration history.
- Run checks and tests before pushing.
- Use issue and pull request templates for future work.
